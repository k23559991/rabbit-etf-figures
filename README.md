# rabbit-etf-figures

토끼 계산기(Rabbit ETF Calculator)가 실행할 때 읽어가는 수치 파일입니다.

## 파일

- `figures.json` — 65개 ETF의 기간별 연평균 총수익률(배당 재투자 기준): 미국 45개 + 한국 20개

## 수치 규칙

- `verified`는 발행사 공식 공시에서 확인된 값만 들어갑니다. 확인되지 않은 기간은 `null`로 잠겨 있습니다.
- `conservative`는 기획 가정값(보수적 수치)으로, 공시가 아닙니다.
- `asOf`는 검증값의 기준일입니다. `version`은 업데이트할 때마다 1씩 오릅니다.
- 종목별 `market`은 US/KR, `currency`는 USD/KRW입니다. 미국 ETF는 달러 기준, 한국 ETF는 원화 기준입니다.

## 갱신

- 매월 1일, 발행사 공시를 확인해 검증된 수치만 갱신합니다.
- 이 파일에는 공개 수치만 들어갑니다. 개인 정보나 비밀값은 없습니다.
